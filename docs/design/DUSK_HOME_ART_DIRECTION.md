# Dusk1.3.0 — The Quiet Workshop

The original Dusk design remains warm paper/midnight ink with terracotta, woodland/slate alternatives, system type, generous editorial hierarchy and independent light/dark/system overlays. The previous CSS horizon was the only generic decoration and disappeared on mobile. The ordinary official-site profile was reviewed read-only; its pre-release copy/feature/FAQ blocks remain site data, not special renderer code.

The Owner-approved art family uses tactile paper/clay folios, arches, material studies and quiet botanical details. No text, logo, person, identifiable building, faux interface or product guarantee is baked into an image. Generic composition suits a small business/publication without installing Railpress marketing copy. Theme art is optional decoration: empty alt, aria-hidden picture, essential headings/links/content remain text. Meaningful author media keeps its own alt/caption/rights and takes priority over the default front hero.

New installs use editorial artwork by default. An upgraded retained Dusk without an explicit artwork choice receives none in its new immutable snapshot; original rows/vendor files stay unchanged. Owner may choose editorial/none, preview and activate. A static front uses the hero and up to three decorative recent-post companions; an empty home uses hero plus rhythm/light-shade companions. Unused images are not requested. This avoids an all-six marketing gallery on every unrelated site. Existing footer/navigation/blog/SEO semantics stay intact.

Hero sits beside real heading text on wide layouts, stacks below58rem, and preserves its central subject at mobile and actual200% zoom. Pictures reserve3:2aspect ratio; srcset selects only exact signed digest-local resources, fallback has explicit360x240dimensions, initial hero is eager/async and below-fold companions lazy. No animation, global invert filter, external CSS image URL or storage/identification script. Light/dark retain original raster colors inside token-based frames; uploaded logos still need image-specific review.

Budget decisions: preserve2MiB aggregate/1MiB per image/1024px side ceilings, with bounded28asset/48file contract for responsive variants. Selected desktop hero26KiBmax; all six1024WebP115KiBtotal. PNG quantization is absent, so a measured360PNGfallback keeps the package small. AVIF is intentionally unshipped until an actual pipeline qualifies. Browser weights, request selection and timing are measured separately; no invented LCP/CLS/INP or universal availability claim.

Six exact master hashes/prompts/permissions are in docs/assets. This art is genuinely generated and reviewed, not a vector substitute or stock download. Old1.2.0installed identities and original/private source are preserved; new1.3.0signed identity requires amended core/decoder support. Public publication, private-site integration, native promotion/revert and comprehensive amended-release qualification remain separately gated.
