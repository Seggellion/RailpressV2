# Public distribution boundary

Allowed source: independently authored CMS/runtime, generic Dusk and reference
fixtures, cleared emblem/illustrations with provenance/licenses, generic tests,
AGENTS/CLAUDE/Harness and public installation/security/privacy/native-operation docs.
Dependencies retain their own licenses; root MIT does not relicense dependencies
or waive trademark rights. The older wordmark is excluded.

Never include private official editorial bodies/review metadata, site-specific
deployment inputs, operational source evidence/recovery, account/TLS/mail/OAuth/
signing credentials, database/media state or private Git objects in public output.
Source, runtime package and private same-host recovery are distinct artifacts.

If a runtime package includes the developer Harness, include its canonical policy,
gateway, docs and actual generic tests too; missing tests must not become a false
verification PASS. A full public source package may be used for this purpose.
Audit generated assets/maps/fonts and packages after compilation, not just Git.
Pattern scans require disposition of intentional synthetic security fixtures.

Uncommitted source requires a per-file manifest independent of inherited HEAD;
freeze before build, verify extracted bytes, and pin the exact immutable artifact.
No remote repository, release signature with production keys or public distribution
is authorized by successful local packaging. Private-site source stays separate.
