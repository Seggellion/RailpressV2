# Contributing

Read AGENTS.md and docs/harness/FEATURE_PLAYBOOK.md. Use an isolated native Linux development checkout and dedicated synthetic PostgreSQL16/MySQL8.4 with private storage/cache/mail. Follow README's patched runtime and guarded migration/test commands. No Docker/Kamal is required or supported.

Describe the concrete problem, core/theme/security boundary, compatibility and rights of contributed code/assets. Run focused tests followed by both affected full engine suites and quality.sh. Preserve failed contexts and record unavailable browser/provider gates honestly. Never add private site content, keys, real account data, historical recovery archives or unlicensed assets.

Submit a small reviewed pull request with commands/results. CI runner provisioning is separate; queued checks are not passing checks. Contributions remain subject to review and the MIT license; do not imply a trademark grant. Report security issues privately using SECURITY.md.
