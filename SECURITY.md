# Security reporting

Railpress2.0 alpha is not production certified. Do not post credentials, private records, exploit payloads exposing third parties, or database dumps in public issues. Use GitHub's private vulnerability reporting for this repository if the maintainer has enabled it; otherwise contact the repository owner privately through an established channel before sending sensitive detail. No dedicated response-time SLA or unconfigured security mailbox is promised.

Include affected commit/version, a minimal synthetic reproduction, expected boundary and impact. Core owns authentication, setup, authorization, deadlines, SEO and host admission; trusted themes execute code. Do not use this preview against production data without an independently qualified deployment and recovery contract.
